# Field Notes

*A reference library of colour, type, and mood*

A small, personal collection of images I keep coming back to, with the colours, type and mood of each: **https://anithvishwanath.github.io/field-notes/**

Every entry has its palette (up to five colours, and how much of the image each takes up), a kind (photo, poster, book and so on), the type where there is any, and up to three moods. You can filter by kind, colour, mood and, where I'm sure of it, type. Type is always an approximation, never a claim about an exact font.

## About this repository

This repository holds only the generated website. It is built from a collection I keep on my own machine and published by a script, which replaces everything here with a single new commit each time. Edits made here won't last, and the code that builds the site is not in this repository. This copy is a snapshot that I republish by hand, so it can lag behind the main site.

## Images

The images belong to their creators. Each page credits the maker and links to the source where I know it. "Unknown" means I haven't been able to find out.

Built with [Astro](https://astro.build) and hosted on GitHub Pages. Palettes are worked out in the OKLCH colour space.
